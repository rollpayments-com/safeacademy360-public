# safeacademy360.com (public mirror)

Read only mirror of the source for [safeacademy360.com](https://safeacademy360.com/), the public website of Safe Academy 360, operated by Roll Payments LLC. Refreshed from the private working repository; pull requests here are not merged. Send proposed changes to Roll Payments.

- `docs/CONTENT_RULES.md`: the rules every word on the site follows. Read first.
- `docs/VICTOR_SEO_PROMPT.md`: the SEO brief.
- `src/`, `data/`, `scripts/`: the static site and its zero dependency build (`npm run build`).
