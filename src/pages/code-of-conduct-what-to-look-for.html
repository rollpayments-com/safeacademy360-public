How to read a martial arts gym's code of conduct

Plenty of academies have a poster on the wall about respect, effort, and bowing before you step on the mat. A code of conduct for coaches and staff is a different document, and it is the one that matters for safety.

The difference between gym rules and a code of conduct

Gym rules are for students: show up on time, keep your uniform clean, bow when you enter the mat. A code of conduct is for coaches, assistants, and staff. It sets the boundaries around how adults interact with minors at the academy, and what happens when someone crosses one. A poster about respect is not a substitute for it.

The five clauses that matter

  • One on one contact. When and where a coach can be alone with a minor, if ever, and what visibility is required.
  • Physical contact. What contact is appropriate for teaching technique, and what is not, stated plainly rather than left to judgment.
  • Changing rooms and travel. Supervision rules for changing areas, and whether coaches transport minors or communicate with them outside class.
  • Messaging and social media. Whether a coach can message a minor directly, and if so, through what channel and with what oversight.
  • Reporting. Who a concern goes to, what is written down, and when the academy involves authorities.

A code missing more than one of these is not doing its job, whatever else it says.

Reading one, if you're handed a document

Look for specifics, not values. "We treat everyone with respect" is a value. "Private lessons happen in view of others" is a rule. A code built from rules can be checked; a code built from values can only be trusted, and trust is not the standard here.

If there isn't one

Ask if one is being written. An academy that has never put its coaching standards on paper has not yet decided what its rules are, which means those rules can change depending on who you ask. Adopting a written code, and having every coach sign it electronically against a dated version, is one of the requirements behind Safe Academy 360 certification; see the full list of questions to ask any academy, certified or not.

What is usually missing

Most codes of conduct cover behaviour on the mat and stop there. Respect the instructor, bow when you step on, no shoes. Useful, but none of it addresses the situations a code exists to govern.

The gaps to look for are one on one contact with minors, communication between coaches and students outside the academy including social media and messaging, changing room and bathroom arrangements, photography, and transport. Each of those is somewhere an incident can begin, and each is straightforward to write a rule about. A code that names them has been thought about. A code that lists only mat etiquette has been copied.

The other common gap is consequences. A rule with no stated consequence, and no named role responsible for applying it, is a preference rather than a policy.
